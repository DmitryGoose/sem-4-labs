# Лабораторная работа №3. Финансовые продукты. Frontend

**Цель работы:** изучение модульной структуры frontend-приложения на JavaScript, построение интерфейса из страниц и компонентов, работа с карточками и переходами между страницами.

Приложение отображает список финансовых продуктов (депозиты, инвестиции, кредитные карты) и позволяет просматривать детали каждого продукта.

## Задание
1. Разработать клиентское SPA с использованием ES-модулей.
2. Создать главную страницу со списком карточек.
3. Реализовать отдельную страницу просмотра выбранного продукта.
4. Применить компонентный подход: папки `pages` и `components`.
5. Использовать Bootstrap для стилизации (тёмная тема).
6. Обеспечить переходы между страницами без перезагрузки браузера.

## Реализованный функционал
- Главная страница (`MainPage`) с динамическим рендерингом карточек
- Страница деталей (`ProductPage`) с информацией о продукте и кнопкой возврата
- Компоненты: `ProductCardComponent`, `ProductComponent`, `BackButtonComponent`, `ToastComponent`
- Всплывающие уведомления (toast) при клике на карточку
- Данные хранятся статически в `getData()` (позже будут заменены на API)

## Запуск
Открыть `index.html` через Live Server.

## Структура проекта
- `index.html` – точка входа
- `main.js` – запуск приложения
- `pages/` – страницы (`main`, `product`)
- `components/` – переиспользуемые компоненты
