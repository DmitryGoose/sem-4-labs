# Лабораторная работа №4. Finance API. Node.js + Express

**Цель работы:** изучение основ backend-разработки на Node.js и Express, создание REST API с хранением данных в JSON-файле.

Сервер предоставляет API для управления финансовыми продуктами: депозиты, инвестиции, кредитные карты.

## Задание
1. Инициализировать npm-проект и установить Express.
2. Реализовать CRUD-операции для сущности `stocks`:
   - `GET /stocks` – список с фильтрацией по названию
   - `GET /stocks/:id` – одна запись
   - `POST /stocks` – создание
   - `PATCH /stocks/:id` – обновление
   - `DELETE /stocks/:id` – удаление
3. Данные хранить в `stocks.json`.
4. Разделить код на слои: routes, controllers, services.
5. Настроить логгирование запросов и обработку ошибок.
6. Протестировать через Postman.

## Реализованный функционал
- Express-сервер с архитектурой, близкой к MVC
- Полный набор CRUD-эндпоинтов
- Валидация обязательных полей при создании/обновлении
- Централизованная обработка ошибок
- Поддержка CORS
- Сервис `fileService` для абстрагирования работы с файловой системой

## Методы API
- `GET /stocks` – список всех продуктов
- `GET /stocks?title=депозит` – фильтрация по названию
- `GET /stocks/1` – получение по id
- `POST /stocks` – добавление (тело: `{ "src": "...", "title": "...", "text": "..." }`)
- `PATCH /stocks/1` – обновление полей
- `DELETE /stocks/1` – удаление

## Запуск
```bash
cd finance-api
npm install
npm run dev
```

# Лабораторная работа №5. Подключение фронтенда к API через XHR. CORS

**Цель работы:** изучение AJAX-взаимодействия frontend-приложения с backend API с использованием `XMLHttpRequest`, а также знакомство с проблемой CORS.

В этой работе фронтенд из ЛР3 подключается к REST API, созданному в ЛР4. Реализована фильтрация, просмотр, добавление и редактирование продуктов (пока без сохранения).

## Задание
1. Заменить статические данные в ЛР3 на запросы к `http://localhost:3000/stocks`.
2. Использовать `XMLHttpRequest` для всех запросов.
3. Реализовать страницу добавления/редактирования продукта с полями (без кнопки «Сохранить»).
4. Продемонстрировать ошибку CORS при открытии с разных портов.
5. Показать обход CORS через расширение «CORS Unblock».

## Реализованный функционал
- Загрузка списка продуктов через `GET /stocks`
- Фильтрация по названию с параметром `?title=`
- Страница деталей продукта (загрузка по `id`)
- Форма добавления / редактирования с предзаполнением данных
- Все запросы через `XMLHttpRequest`
- Наглядная демонстрация проблемы CORS и её решение расширением

## Особенности демонстрации
1. Запустить backend ЛР4 (`npm run dev` в папке `finance-api`).
2. Запустить фронтенд ЛР5 через Live Server.
3. Открыть DevTools → Network → XHR.
4. При выключенном расширении CORS Unblock видна ошибка.
5. Включить расширение – запросы выполняются успешно.

## Запуск
- Backend: `cd finance-api && npm run dev`
- Frontend: открыть `index.html` через Live Server

## Структура проекта
- `pages/main/index.js` – главная страница с XHR-запросами
- `pages/product/index.js` – страница продукта
- `pages/form/index.js` – страница формы
- `components/stock-form/` – компонент формы

# Лабораторная работа №6. Fetch, Webpack, Интеграция с сервером

**Цель работы:** замена колбеков на промисы, использование `fetch`, сборка фронтенда бандлером и раздача статики через сервер Express.

Фронтенд-приложение полностью интегрируется с бэкендом, устраняя необходимость в CORS-расширениях.

## Задание
1. Заменить все `XMLHttpRequest` на `fetch` с `async/await`.
2. Добавить кнопку «Сохранить» на форму (создание/редактирование через API).
3. Собрать фронтенд Webpack’ом в один `bundle.js`.
4. Настроить сервер Express на раздачу статики из папки `public`.
5. Перенести `bundle.js`, `index.html` и 3D-модель в `public`.
6. Убедиться, что запросы идут на тот же origin (порт 3000) и CORS не требуется.
7. Во вкладке Sources браузера должен быть только `bundle.js`.

## Реализованный функционал
- `fetch` для всех взаимодействий с API
- Кнопка «Сохранить» отправляет POST/PATCH запросы
- После сохранения автоматический возврат на главную с обновлённым списком
- Webpack собирает ES-модули в минифицированный бандл
- Сервер Express раздаёт фронтенд и API на одном порту
- Добавлена вращающаяся 3D-модель пачки купюр (Three.js) на главную страницу
