# Лабораторные работы №1 и №2: Разработка адаптивного интерфейса и логики калькулятора

## Проект: Вычислительный инструмент для портала «КубаньАрхеология»

### Цель работы
1. Спроектировать и реализовать адаптивный пользовательский интерфейс калькулятора с использованием семантической разметки HTML5 и кастомных стилей CSS3 в единой стилистике с основным сайтом.
2. Разработать программную логику на языке JavaScript для выполнения арифметических расчетов, обработки исключений и управления состоянием приложения.

---

## Описание реализации

### 1. Интерфейс и Стилизация (HTML5 / CSS3)
* **Семантическая структура:** Использованы теги `<header>`, `<nav>`, `<section>` и `<footer>`, обеспечивающие правильное структурирование документа.
* **Тематическое оформление:** Интерфейс адаптирован под темную тему археологического портала (`.dark-page`). Использован благородный золотой акцент (`#d4af37`), ассоциирующийся с артефактами, и фирменный голубой цвет (`#00a0e3`) для ключевых элементов управления.
* **Адаптивность и эффекты:** Кнопки спроектированы в виде круглых интерактивных элементов с плавным изменением цвета при наведении (`transition: 0.2s`) и визуальным откликом на клик (`transform: scale(0.95)`).

### 2. Программная логика (JavaScript)
Логика калькулятора реализована на базе конечного автомата, отслеживающего четыре ключевых параметра состояния: `a` (первое число), `b` (второе число), `selectedOperation` (текущий оператор) и `expressionResult` (результат).

**Ключевые инженерные решения в коде:**
* **Защита от некорректного ввода:** Внедрена проверка, блокирующая ввод множественных точек в дробной части одного числа (`digit !== '.' || ... !a.includes('.')`).
* **Обработка критических ошибок:** При попытке деления операнда на `0` система не падает с `Infinity`, а выводит на экран валидное сообщение `ERROR` и безопасно сбрасывает состояние.
* **Повышенная точность вычислений:** Для устранения стандартных проблем JavaScript с округлением чисел с плавающей точкой (например, $0.1 + 0.2 = 0.30000000000000004$) применено форматирование результата до 10 знаков после запятой с последующим отсечением незначащих нулей:
