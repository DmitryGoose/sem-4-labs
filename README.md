# Лабораторная работа №1. Калькулятор. HTML/CSS

**Цель работы:** знакомство с инструментами построения пользовательских интерфейсов web-сайтов: HTML, CSS.

В ходе выполнения работы предстояло создать статическую вёрстку калькулятора на тему «КубаньАрхеология» и оформить её в тёмном стиле.

## Задание
1. Создать HTML-разметку калькулятора: экран и кнопки (цифры, операции, очистка, смена знака, процент).
2. Присвоить элементам уникальные id для последующей работы с JavaScript.
3. Создать файл стилей `style.css` и подключить его.
4. Оформить кнопки согласно методичке: круглые кнопки, разные цвета для цифр, операций и специальных действий.
5. Реализовать адаптивную тёмную тему с фоновым изображением.

## Реализованный функционал
- Семантическая HTML-структура калькулятора
- Тёмная тема в стиле «КубаньАрхеология» с логотипом и подвалом
- Кнопки с классами `.my-btn`, `.primary`, `.secondary`, `.execute`
- Экран калькулятора с тёмным фоном и белым текстом
- Ховер-эффекты и активные состояния кнопок

## Запуск
Открыть файл `calculator.html` через Live Server в VS Code.

## Структура проекта
- `calculator.html` – разметка калькулятора
- `style.css` – стилизация

# Лабораторная работа №2. Калькулятор. JavaScript

**Цель работы:** знакомство с JavaScript на примере добавления логики к калькулятору.

Продолжение предыдущей работы – добавлена функциональность арифметических вычислений, смена знака, вычисление процентов и обработка ошибок.

## Задание
1. Подключить файл `script.js`.
2. Получить доступ к элементам калькулятора через `getElementById` и `querySelectorAll`.
3. Реализовать ввод чисел по цифрам (переменные `a` и `b`).
4. Написать обработчики для операций `+`, `-`, `×`, `÷`.
5. Кнопка `C` сбрасывает состояние.
6. Кнопка `=` выполняет вычисление с учётом выбранной операции.
7. Обработка десятичной точки, запрет дублирования.
8. Дополнительно: смена знака `±`, вычисление процента `%`, защита от деления на ноль.
9. Форматирование результата (ограничение длины) для предотвращения выхода за экран.

## Реализованный функционал
- Полноценный калькулятор с базовыми арифметическими операциями
- Обработка ошибок (деление на ноль выводит `ERROR`)
- Ограничение количества знаков после запятой
- Возможность продолжать вычисления с результатом
- Стилистика осталась неизменной (тёмная тема «КубаньАрхеология»)

## Запуск
Открыть `calculator.html` через Live Server.

## Структура проекта
- `calculator.html`
- `style.css`
- `script.js` – вся логика калькулятора
