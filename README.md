# Лабораторная работа №3. Финансовые продукты и карточки. Frontend. JavaScript

## Цель работы
Изучение модульной структуры frontend-приложения на JavaScript, построение интерфейса из страниц и компонентов, работа с карточками, динамическими формами и переходами между ними, а также сборка проекта с помощью Webpack.

## Задание
Разработать клиентское приложение по теме «Финансовые продукты и предложения».
Необходимо реализовать:
* главную страницу со списком карточек финансовых продуктов;
* отдельную страницу просмотра выбранного продукта;
* интерактивную управляемую форму для добавления и редактирования продуктов;
* модульную структуру проекта с разделением на pages и components;
* стилизацию интерфейса с использованием компонентов Bootstrap 5;
* систему динамических всплывающих уведомлений (Toasts);
* сборку проекта с помощью сборщика Webpack.

## Реализованный функционал
* создана главная страница (витрина) со списком финансовых предложений;
* реализована страница детального просмотра параметров конкретного продукта (ставки, лимиты, сроки);
* добавлена интерактивная форма `StockFormComponent`, поддерживающая два режима: добавление нового продукта и редактирование существующего;
* внедрен модуль `showToast` для вывода кастомизированных уведомлений Bootstrap при клике на «Показать предложение»;
* реализована callback-архитектура (компоненты общаются через функции-слушатели, что исключает прямую зависимость друг от друга);
* проект разделен на логические модули pages и components;
* настроена сборка и минификация кодовой базы через Webpack.

## Запуск
Порядок запуска:
1. Открыть папку `Lab3_Cards` в терминале;
2. Выполнить команду `npm install` для установки всех зависимостей;
3. Запустить локальный сервер разработки командой `npm run start` (или `npm run dev`);
4. Открыть появившийся в терминале адрес в браузере (по умолчанию `http://localhost:8080`).

## Структура проекта
* `index.html` — корневой HTML-файл приложения;
* `main.js` — точка входа;
* `webpack.config.cjs` — конфигурационный файл сборщика Webpack;
* `package.json` — манифест проекта, содержащий скрипты и зависимости;
* `pages` — логические экраны приложения (главная, продукт, форма);
* `components` — переиспользуемые UI-компоненты:
  * `product` — компонент для детального отображения продукта;
  * `product-card` — интерактивная карточка продукта для главного экрана;
  * `stock-form` — управляемая форма ввода и валидации данных;
  * `toast` — утилитарный модуль для генерации всплывающих окон.
